# play

A research lens on play — one of Sankha Cooray's research lenses.

## Members

This lens groups the following projects (see `play-sankhacooray-com.code-workspace`):

- **shadow-play** — A creative-coding toy exploring light, shadow, and gesture in the browser.
- **magic-bells** — A Unity application — interactive sound and motion as play.
